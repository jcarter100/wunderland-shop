# WUNDERLAND RECORDS — Official Store

Static storefront for WUNDERLAND RECORDS, served by GitHub Pages at
**https://shop.wunderland.gg** (custom domain set via the `CNAME` file).

- Plain HTML/CSS/JS — no build step. `index.html` is the entry point.
- Product catalog lives in `data/`, client logic in `js/`, styles in `css/`.
- `.nojekyll` disables Jekyll processing so all files are served as-is.

To deploy changes, commit and push to `main`; GitHub Pages rebuilds automatically.
